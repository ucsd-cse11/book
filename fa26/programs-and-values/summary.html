Fill in the type of each definition so the program runs.
radius = 25;
label = "Radius: " + radius;
half = 12.5;
dot = new Circle(radius, "red");
Exactly one of these definitions runs without an error. Which one?
  1. string name = "Val";
    The type is spelled String, with a capital S.
  2. int count = "5";
    "5" is a string. An int definition needs a number without quotes, like 5.
  3. int total = 7 / 2;
  4. Pict p = new Circle("10", "red");
    Circle takes an int radius. "10" is a String, even though it looks like a number.
