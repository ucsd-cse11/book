Progress Tracking Demo

This page plays the part of a course site like PrairieLearn. Open opens a chapter in a new window with ?report= set to this page's origin. As the reader works through the chapter (running code, answering questions, moving between steps), the chapter posts a progress snapshot back here. This page acknowledges each one, and the chapter's header then shows "Progress recorded".

Progress is tracked in the reader's own browser and is a nudge, not a grade: the chapter only reports what it saw happen.
