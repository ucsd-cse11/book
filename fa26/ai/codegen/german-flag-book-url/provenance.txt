**Using a method, like the book's `drawFlag`:** In the "More Methods" chapter, the book puts a flag's colors in a record and draws them with a `drawFlag` method. The same idea works for flags with horizontal stripes:

```java
record HorizontalFlag(String top, String middle, String bottom) {
  Pict drawFlag(int width, int height) {
    return new Above(new Rect(width, height, this.top),
                     new Above(new Rect(width, height, this.middle),
                               new Rect(width, height, this.bottom)));
  }
}

void main() {
  HorizontalFlag de = new HorizontalFlag("black", "red", "yellow");
  Pict dePic = de.drawFlag(100, 20);
  Pict bigDe = de.drawFlag(300, 60);
  ImageIO_.show(dePic);
  ImageIO_.show(bigDe);
}
```

You can reuse the record for other flags with three horizontal stripes. For example, `new HorizontalFlag("white", "blue", "red")` draws Russia's flag.
