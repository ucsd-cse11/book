Practice: true or false

input.next() reads a whole line.
  1. True
    next() reads one piece — the characters up to the next space. nextLine() is the one that reads a whole line.
  2. False
input.hasNext() answers true or false about whether there is another piece to read.
  1. True
  2. False
    hasNext() is the loop’s question: “another piece?” When it says false, the pieces are done.
A PrintWriter writes to the file as soon as you call println, so you never need close().
  1. True
    close() finishes the file — forget it, and the last lines might never land.
  2. False
A throw stops the method immediately; the lines after it don’t run.
  1. True
  2. False
    throw stops the method on the spot — the lines after it never run, and the total never gets printed. That’s what the gloves example in step 4 shows.
throw new IllegalArgumentException(); with no message is fine, because the exception type says enough.
  1. True
    The type says what kind of problem it is, but the message says which gear and which value. Without it, the reader has to go find the throw to learn anything.
  2. False
Calling file.exists() checks whether the file represented by file exists and returns a boolean indicating the result.
  1. True
  2. False
    file.exists() takes no arguments. The File object already represents a specific path. It returns true if a file or directory exists at that path, and false otherwise.
A catch block runs only if the try block throws that kind of exception.
  1. True
  2. False
    If nothing throws in the try, the catch blocks are skipped and the program carries on after them.
