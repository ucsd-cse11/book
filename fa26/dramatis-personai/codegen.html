Given only ‘Write a Java program that creates an image of the German flag’ · Opus 5.5 · 2026-11-11 · how this was made

Claude: Here’s a Java program that generates the German flag as a PNG. The flag has three equal horizontal bands of black, red, and gold, in the official 3:5 aspect ratio.

import java.awt.Color;
import java.awt.Graphics2D;
import java.awt.image.BufferedImage;
import java.io.File;
import java.io.IOException;
import javax.imageio.ImageIO;

public class GermanFlag {

    // Official colors (RGB approximations from the German federal government)
    private static final Color BLACK = new Color(0x00, 0x00, 0x00);
    private static final Color RED   = new Color(0xDD, 0x00, 0x00);
    private static final Color GOLD  = new Color(0xFF, 0xCE, 0x00);

    public static void main(String[] args) {
        int width = 1000;                   // default width in pixels
        String outputFile = "german_flag.png";

        if (args.length >= 1) {
            width = Integer.parseInt(args[0]);
        }
        if (args.length >= 2) {
            outputFile = args[1];
        }

        int height = width * 3 / 5;         // official 3:5 aspect ratio

        BufferedImage image = createFlag(width, height);

        try {
            ImageIO.write(image, "png", new File(outputFile));
            System.out.println("Saved " + width + "x" + height + " flag to " + outputFile);
        } catch (IOException e) {
            System.err.println("Error writing image: " + e.getMessage());
            System.exit(1);
        }
    }

    public static BufferedImage createFlag(int width, int height) {
        BufferedImage image = new BufferedImage(width, height, BufferedImage.TYPE_INT_RGB);
        Graphics2D g = image.createGraphics();

        // Compute band boundaries so the three bands fill the height exactly,
        // even when height isn't divisible by 3.
        int band1End = height / 3;
        int band2End = 2 * height / 3;

        g.setColor(BLACK);
        g.fillRect(0, 0, width, band1End);

        g.setColor(RED);
        g.fillRect(0, band1End, width, band2End - band1End);

        g.setColor(GOLD);
        g.fillRect(0, band2End, width, height - band2End);

        g.dispose();
        return image;
    }
}

How to run

javac GermanFlag.java
java GermanFlag                     # creates german_flag.png at 1000x600
java GermanFlag 500                 # creates a 500x300 flag
java GermanFlag 1500 flag.png       # custom size and filename

Notes

  • Colors: Black #000000, red #DD0000, and gold #FFCE00 are commonly used RGB values for the official flag colors.
  • Proportions: The official ratio is height:width = 3:5, and the three bands have equal height.
  • Uneven heights: The band boundaries are computed as height/3 and 2*height/3 rather than adding a fixed band height three times. That way, no rows are left blank at the bottom when the height isn’t a multiple of 3.
  • Dependencies: It uses only the standard library (java.awt and javax.imageio). No graphical display is needed, so it also works on headless servers. If you run into AWT errors, add -Djava.awt.headless=true.

#lang racket
(require pict)

(provide german-flag)

;; The German flag: three equal horizontal bands of
;; black, red, and gold, with a 3:5 aspect ratio.
(define (german-flag [width 300])
  (define height (* width 3/5))
  (define band-height (/ height 3))
  (define (band color)
    (filled-rectangle width band-height
                      #:color color
                      #:draw-border? #f))
  (vl-append
   (band (make-object color% 0 0 0))       ; black
   (band (make-object color% 221 0 0))     ; red  (#DD0000)
   (band (make-object color% 255 206 0)))) ; gold (#FFCE00)

(module+ main
  (require file/convertible)
  (define flag (german-flag))
  (with-output-to-file "german-flag.png" #:exists 'replace
    (λ () (write-bytes (convert flag 'png-bytes))))
  flag)
  • Shape: each band is a filled-rectangle with no border, and vl-append stacks them. The flag uses the official 3:5 ratio, and the width is an optional argument that defaults to 300.
  • Colours: the RGB values are the common screen versions of the official colours: black, red #DD0000 and gold #FFCE00.
  • Saving: the main submodule saves the image as german-flag.png when you run racket german-flag.rkt.

import java.awt.Color;
import java.awt.image.BufferedImage;
import java.io.File;
import java.io.IOException;
import javax.imageio.ImageIO;

/** A simple picture: a fixed-size grid of colored pixels. */
class Pict {
    private final int width;
    private final int height;
    private final Color[][] pixels; // pixels[row][col]

    Pict(int width, int height, Color background) {
        if (width <= 0 || height <= 0) {
            throw new IllegalArgumentException("Pict dimensions must be positive");
        }
        this.width = width;
        this.height = height;
        this.pixels = new Color[height][width];
        fillRect(0, 0, width, height, background);
    }

    int getWidth()  { return width; }
    int getHeight() { return height; }

    Color getPixel(int x, int y)              { return pixels[y][x]; }
    void  setPixel(int x, int y, Color color) { pixels[y][x] = color; }

    /** Fill the rectangle with top-left corner (x, y) and size w x h, clipped to bounds. */
    void fillRect(int x, int y, int w, int h, Color color) {
        for (int r = Math.max(0, y); r < Math.min(height, y + h); r++) {
            for (int c = Math.max(0, x); c < Math.min(width, x + w); c++) {
                pixels[r][c] = color;
            }
        }
    }

    /** Save this picture as a PNG file. */
    void save(String filename) throws IOException {
        BufferedImage img = new BufferedImage(width, height, BufferedImage.TYPE_INT_RGB);
        for (int r = 0; r < height; r++) {
            for (int c = 0; c < width; c++) {
                img.setRGB(c, r, pixels[r][c].getRGB());
            }
        }
        ImageIO.write(img, "png", new File(filename));
    }
}

public class GermanFlag {
    // Official German flag colors
    static final Color BLACK = new Color(0x00, 0x00, 0x00);
    static final Color RED   = new Color(0xDD, 0x00, 0x00);
    static final Color GOLD  = new Color(0xFF, 0xCE, 0x00);

    /** Three equal horizontal stripes (black, red, gold) at the official 3:5 ratio. */
    static Pict makeGermanFlag(int width) {
        int height = width * 3 / 5;
        int stripe = height / 3;
        Pict flag = new Pict(width, height, BLACK);
        flag.fillRect(0, 0,          width, stripe,              BLACK);
        flag.fillRect(0, stripe,     width, stripe,              RED);
        flag.fillRect(0, 2 * stripe, width, height - 2 * stripe, GOLD); // absorbs rounding
        return flag;
    }

    public static void main(String[] args) throws IOException {
        Pict flag = makeGermanFlag(500);
        flag.save("german_flag.png");
        System.out.println("Wrote german_flag.png (" + flag.getWidth() + "x" + flag.getHeight() + ")");
    }
}

GermanFlag.java

class GermanFlag {
    public static void main(String[] args) {
        // The official German flag has a 3:5 ratio (height:width),
        // with three equal horizontal stripes: black, red, gold.
        int width = 500;
        int stripeHeight = 100;   // 3 stripes * 100 = 300 tall, so 300:500 = 3:5

        Pict black = new Rect(width, stripeHeight, "black");
        Pict red   = new Rect(width, stripeHeight, "#DD0000");  // official flag red
        Pict gold  = new Rect(width, stripeHeight, "#FFCE00");  // official flag gold

        // a.above(b) puts a on top of b
        Pict flag = black.above(red).above(gold);

        ImageIO_.show(flag);
        ImageIO_.save(flag, "german-flag.png");
    }
}

To compile and run, put GermanFlag.java in the same folder as Pict.java, then:

javac Pict.java GermanFlag.java
java GermanFlag

How it works:

  • Colors: The kit’s named colors don’t include gold, so I used hex strings, which the kit also accepts. #DD0000 and #FFCE00 are close to the official flag colors. You could use "red" and "yellow" instead, but they won’t look quite right.
  • Stacking: a.above(b) puts a on top of b, so black.above(red).above(gold) stacks the stripes from top to bottom.
  • Output: ImageIO_.show opens a window. On a computer without a display it writes shown-1.png instead. ImageIO_.save also writes the flag to german-flag.png.

Given a web fetch tool and ‘Read the whole book at https://ucsd-cse11.github.io/book/fa26/ and then write a program in that style that makes a Pict of the German flag’ · Opus 5.5 · 2026-11-11 · how this was made

Claude: I read through the whole book. Here’s a German flag in the same style as its French flag example. That example puts three Rects next to each other with Beside, inside a top-level void main(), and shows the result with ImageIO_.show. The German flag has horizontal stripes, so this version stacks them with Above instead:

void main() {
  int w = 100;
  int h = 20;
  Pict black = new Rect(w, h, "black");
  Pict red = new Rect(w, h, "red");
  Pict gold = new Rect(w, h, "yellow");
  Pict redgold = new Above(red, gold);
  Pict flag = new Above(black, redgold);
  System.out.println(flag);
  ImageIO_.show(flag);
}

Each stripe is 100 by 20, so the flag is 100 wide and 60 tall. That’s the real 5:3 shape of the German flag.

About the gold stripe: Pict’s 16 named colors don’t include gold, so I used "yellow", the closest one. To get the official gold (new Color(255, 206, 0)), you’d have to build that stripe as a Raster, which is more work than this example needs.

Using a method, like the book’s drawFlag: In the “More Methods” chapter, the book puts a flag’s colors in a record and draws them with a drawFlag method. The same idea works for flags with horizontal stripes:

record HorizontalFlag(String top, String middle, String bottom) {
  Pict drawFlag(int width, int height) {
    return new Above(new Rect(width, height, this.top),
                     new Above(new Rect(width, height, this.middle),
                               new Rect(width, height, this.bottom)));
  }
}

void main() {
  HorizontalFlag de = new HorizontalFlag("black", "red", "yellow");
  Pict dePic = de.drawFlag(100, 20);
  Pict bigDe = de.drawFlag(300, 60);
  ImageIO_.show(dePic);
  ImageIO_.show(bigDe);
}

You can reuse the record for other flags with three horizontal stripes. For example, new HorizontalFlag("white", "blue", "red") draws Russia’s flag.
