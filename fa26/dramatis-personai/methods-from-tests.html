Given the program so far and ‘Implement the contains method for polygon in this code.’ · Opus 5.5 · 2026-11-11 · how this was made
Claude:  Here’s an implementation of Polygon.contains that uses ray casting (the even-odd rule), with a separate check so points on the outline count as inside:
record Polygon(Point[] outline) implements Region {
  public boolean contains(Point p) {
    int n = this.outline.length;
    boolean inside = false;
    // Look at each edge (a, b), wrapping from the last point back to the first
    for (int i = 0, j = n - 1; i < n; j = i, i += 1) {
      Point a = this.outline[j];
      Point b = this.outline[i];

      // Points on the outline count as inside, like RectRegion and CircRegion
      if (onSegment(a, b, p)) { return true; }

      // Cast a ray from p to the right and count how many edges it crosses.
      // Only count edges that cross p's y value. Using strict > on both ends
      // means a vertex exactly at p.y() is only counted once.
      if ((a.y() > p.y()) != (b.y() > p.y())) {
        // x position where this edge crosses the line y = p.y()
        double xCross = a.x() + (p.y() - a.y()) * (b.x() - a.x()) / (b.y() - a.y());
        if (p.x() < xCross) { inside = !inside; }
      }
    }
    return inside;
  }

  // Is p on the segment from a to b?
  private static boolean onSegment(Point a, Point b, Point p) {
    // Cross product is 0 when a, b, and p are on the same line
    double cross = (b.x() - a.x()) * (p.y() - a.y()) - (b.y() - a.y()) * (p.x() - a.x());
    if (cross != 0) { return false; }
    // p must also be between a and b
    return p.x() >= Math.min(a.x(), b.x()) && p.x() <= Math.max(a.x(), b.x())
        && p.y() >= Math.min(a.y(), b.y()) && p.y() <= Math.max(a.y(), b.y());
  }
}
How it works
  1. Outline check. For each edge, onSegment tests whether p lies on it. The cross product is zero only when p is on the line through a and b. The bounds check then makes sure p is between them. This is why the tests for corners like (10, 10) and edges like (10, 15) return true.
  2. Ray casting. Picture a ray going from p to the right forever. Each time it crosses an edge, it moves from inside to outside or back again. An odd number of crossings means p is inside.
    • The test (a.y() > p.y()) != (b.y() > p.y()) keeps only edges that span p’s y value. Horizontal edges are skipped automatically, which also avoids dividing by zero in the xCross line.
    • Because the comparison is strict on both ends, a ray that passes exactly through a vertex is counted once, not twice.
Checking one case by hand. For (5, 15) in lShape, only two edges span y = 15:
  • the edge at x = 0, which is to the left of 5, so it doesn’t count;
  • the edge at x = 10, which is to the right, so it counts.
That’s one crossing, which is odd, so the result is inside. For (15, 15), both of those edges are to the left, giving zero crossings, so the result is outside.
The same approach works for any simple polygon, including concave ones like lShape, staircase, and trapezoid.
One caveat: the cross != 0 test is exact. That works for the integer coordinates in these tests. With arbitrary decimal coordinates, rounding errors could make a point that is really on an edge fail the check. If that matters, you could compare Math.abs(cross) against a small tolerance instead.
