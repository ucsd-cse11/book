// the same outline, starting from point number start
Polygon startingAt(int start) {
  Point[] result = new Point[this.outline.length];
  for (int i = 0; i < result.length; i += 1) {
    result[i] = this.outline[(start + i) % result.length];
  }
  return new Polygon(result);
}
// the same outline, backwards
Polygon reversed() {
  Point[] result = new Point[this.outline.length];
  for (int i = 0; i < result.length; i += 1) {
    result[i] = this.outline[result.length - 1 - i];
  }
  return new Polygon(result);
}

Student: And what about the slanted sides? Could we check those for real, with an oracle and a generator, like we did for skylines?
Prof: We’d need a shape with a slanted side whose contains we can write ourselves and believe. Here’s the simplest one I know: a right triangle with its square corner at (0, 0). Let’s call it a ramp.
a ramp, 4 wide and 3 tall
A point is in the ramp when it isn’t left of the y-axis, isn’t below the x-axis, and isn’t past the slanted side.
Student: The first two are easy. How do I tell if a point is past the slanted side?
Prof: Walk along the slanted side from the bottom right corner up to the top. As x goes from width down to 0, y goes from 0 up to height. Everywhere on that side, x / width + y / height is exactly 1. Inside the ramp it’s less than 1. I’ll multiply both sides by width * height, so the method never has to divide:
// a right triangle with its square corner at (0, 0)
record RampRegion(double width, double height) implements Region {
  public boolean contains(Point p) {
    return p.x() >= 0 && p.y() >= 0
        && p.x() * this.height + p.y() * this.width <= this.width * this.height;
  }
}
Student: Let me try a point from the picture. (2, 1.5) is halfway up the slanted side. 2 × 3 + 1.5 × 4 is 12, and 4 × 3 is 12. So it’s right on the edge, and it counts as inside. OK, I believe that one.
Prof: Then the check looks just like checkSkyline. Build the same ramp as a Polygon with three points, ask both at every grid point, and compare. And a generator can pick the widths and heights:
// the same ramp as a three-point Polygon, asked at every grid point
int checkRamp(int width, int height) {
  Polygon outline = new Polygon(new Point[] {
      new Point(0, 0), new Point(width, 0), new Point(0, height) });
  Region ramp = new RampRegion(width, height);
  int checks = 0;
  for (int i = 0; i < 100; i += 1) {
    for (int j = 0; j < 100; j += 1) {
      Point p = new Point(-5 + i * 0.5, -5 + j * 0.5);
      assertEquals(ramp.contains(p), outline.contains(p), "at " + p);
      checks += 1;
    }
  }
  return checks;
}
int checkRandomRamps(int count, int seed) {
  Random random = new Random(seed);
  int checks = 0;
  for (int r = 0; r < count; r += 1) {
    checks += checkRamp(1 + random.nextInt(40), 1 + random.nextInt(40));
  }
  return checks;
}
