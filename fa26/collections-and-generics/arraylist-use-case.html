Using ArrayList with Post

Student: Ok Professor, I think I’m ready to use an ArrayList in my own programs.
Prof: Sure, let’s go back to an example we have gone over before. We made a Post class.
Prof: Imagine we wanted to support replies on our posts. How would you go about implementing replies to a post using an ArrayList?
Student: I should have every Post contain an ArrayList of replies, and the type should be other posts, so I’ll use an ArrayList<Post>.
Prof: Good idea. You should also include a reference to the Post it’s replying to, since each reply is also a Post.
Student: Ok, I understand.
Student: Ok now I am going to add a reply() method. It needs to make a new Post() and set replyTo to be the original Post. And then add this new reply to the ArrayList.
Prof: Implement that method. After you run it, let’s take a moment to think through what it actually builds in memory.
Prof: Here’s the picture just after both reply calls, but before we read count and backUser:

Prof: Each reply did two things at once: it made a new Post and pointed that post’s replyTo back at the one it was replying to. That leaves a link from the original to the reply through the list, and from the reply back to the original through replyTo.
Student: Now for the likes. Since we are using references, whenever we like a Post it shouldn’t matter whether I reach it through the variable r or through original.replies.get(0). They both point at the same object, so liking one should show up on the other.
Prof: Exactly, the posts are mutable. They can be changed without making a copy.
Student: So we’ve been using ArrayList, HashSet, and HashMap. They have a lot of similarities — are they connected in any way?
Prof: They sure are. Each one of these classes implements an interface. ArrayList is one kind of List, and a List is a kind of Collection. HashSet is a Set, which is also a Collection. HashMap is a bit different as a Map holds key/value pairs rather than single elements. Here’s the class hierarchy for that.

Prof: Because ArrayList is a List, you will sometimes see the field written as List<Post> replies instead of ArrayList<Post>. We only covered one type of list, but you will learn about others in future classes. The full set of methods each one offers is in the Java documentation.
Practice
After Post r = p.reply("ada", "hi"); runs, which of these is true?
  1. p.replies contains r and r.replyTo is p
  2. p.replies contains a copy of r, and r.replyTo is null
  3. r.replies contains p and p.replyTo is r
  4. p.replies is unchanged until like() is called
Fill in reply so the new post is linked in both directions: it remembers its parent, and the parent remembers it. main should end with 1 printed for the number of replies.
import java.util.ArrayList;

class Post {
  String user;
  ArrayList<Post> replies = new ArrayList<Post>();
  Post replyTo;
  Post(String user) { this.user = user; }

  Post reply(String user) {
    Post r = new Post(user);
    
    
    return r;
  }
}

void main() {
  Post p = new Post("joe");
  Post r = p.reply("ada");
  System.out.println(p.replies.size());
