@Override
public boolean equals(Object other) {
    if (this == other) return true;
    if (!(other instanceof Raster r)) return false;
    if (this.width() != r.width() || this.height() != r.height()) return false;
    for (int y = 0; y < this.height(); y++) {
        if (!Arrays.equals(this.pixels[y], r.pixels[y])) return false;
    }
    return true;
}

Why does equals compare the names with .equals, but the sizes with ==?
  1. name is a String, an object, and sizeKb is an int
    Strings are objects, so == would ask whether the two names are the same object, like the "trash panda" example from the memory chapter. ints are numbers, so == compares the numbers.
  2. name is a field, and sizeKb isn’t
    Both are fields. What matters is their types.
  3. == doesn’t compile on Strings
    == on two Strings compiles fine. It just asks a different question: are they the same object?
