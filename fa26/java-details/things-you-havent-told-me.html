Student: That’s so weird because I thought when you call methods the receiver decides it.

slice builds a new array out of part of another one, from index start up to (but not including) index end, just like substring does for a String. Write an overload of slice that takes only arr and start, and slices all the way to the end of the array. It can call the slice that’s already there.
int[] slice(int[] arr, int start, int end) {
  int[] result = new int[end - start];
  int index = 0;
  for (int i = start; i < end; i += 1) {
    result[index] = arr[i];
    index += 1;
  }
  return result;
}
