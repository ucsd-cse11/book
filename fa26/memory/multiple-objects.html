Student: Oh! So to tell apart the first two calls, it has to know which object is used for each, menu or pricyMenu.
Prof: Exactly.
Student: That’s cool. So the first call uses menu, the second uses pricyMenu. Oh and the values in the menu one get updated twice. Why is that?
Prof: That corresponds to the two calls to discountInPlace on menu. The first time through, it updates all the values once. The second time is still working with the same array, so it updates it again.
