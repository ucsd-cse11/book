Math measures angles in radians. Finish Point so that angle() is the angle from the positive x axis, turning counterclockwise, up to the point, and degrees() is the same angle in degrees. For the point (1, 1) that is π/4 radians, or 45 degrees.
record Point(double x, double y) {
    double angle() {
        return Math.(y, x);
    }
    double degrees() {
        return Math.(this.angle());
    }
}
Point p = new Point(1.0, 1.0);
double angle = p.angle();
double degrees = p.degrees();
