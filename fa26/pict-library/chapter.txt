# Appendix: The Pict Library

## [Pict Library Reference](pict-library.html)

### Shapes

- `Circle(int radius, String color)`
- `CircleOutline(int radius, String color)`
- `Rect(int width, int height, String color)`
- `RectOutline(int width, int height, String color)`
- `Triangle(int width, int height, String color)`
- `TriangleOutline(int width, int height, String color)`
- `Text(String content, int size, String color)`

A size of `0` makes an empty picture, such as `new Rect(0, 0, "white")`: it takes up no room, so it is a handy starting point for building a picture up piece by piece. A negative size is an error.

### Colors

`"red"`, `"green"`, `"blue"`, `"yellow"`, `"orange"`, `"pink"`, `"magenta"`, `"cyan"`, `"purple"`, `"brown"`, `"black"`, `"white"`, `"gray"`, `"grey"`, `"lightgray"`, `"darkgray"`

`"transparent"` paints nothing, but takes up its size like any other picture.

### Fractional Sizes and Angles

Every size, position, thickness, and angle above also accepts a `double`, rounded to the nearest whole pixel or degree. A picture stores and prints whole numbers either way. A measurement of `NaN` or infinity is an error.

- `Circle(double radius, String color)`
- `CircleOutline(double radius, String color)`

- `RectOutline(double width, double height, String color)`

### Rasters

A `Raster` is a rectangle of pixels, each a `Color` from `java.awt` (start the file with `import java.awt.Color;`). `x` counts across from the left and `y` counts down from the top, both starting at `0`.

- `Raster(Color[][] pixels)` – one inner array per row, top row first; every row must have the same length, and no pixel may be `null`. The raster copies the array, so changing `pixels` afterward does not change it.
- `Raster(int width, int height)` – every pixel transparent
- `int width()` – the length of each row
- `int height()` – the number of rows
- `Color colorAt(int x, int y)` – the pixel in row `y`, column `x`
- `void setColorAt(int x, int y, Color color)`
- `FromRaster(Raster raster)` – a `Pict` that shows the raster’s pixels

Two rasters are `equals` when they have the same size and the same color at every pixel, however they were made. `Pict.render()` turns any picture into a raster.

### Java Colors

- `Color.RED`, `Color.GREEN`, `Color.BLUE`, `Color.WHITE`, `Color.BLACK`, and the other names in `java.awt.Color`
- `new Color(int r, int g, int b)` – red, green, and blue amounts from `0` to `255`
- `new Color(int r, int g, int b, int alpha)` – `alpha` `0` is fully transparent, `255` fully solid

A `Color` prints as `java.awt.Color[r=…,g=…,b=…]`, without its alpha, so a transparent pixel prints the same as black.

### Showing and Saving

- `ImageIO_.show(Pict p)`
- `ImageIO_.show(Raster r)`
- `ImageIO_.save(Pict p, String filename)`
- `ImageIO_.save(Raster r, String filename)`
- `ImageIO_.save(Pict[] frames, String filename)` — an animated GIF, 100 ms per frame, looping
- `ImageIO_.save(Pict[] frames, int delayMs, String filename)`
- `ImageIO_.save(Pict[] frames, int delayMs, boolean loop, String filename)`
- `ImageIO_.load(String filename)` – a `Raster`; a file you saved wins over one of the book’s images with the same name
- `ImageIO_.render(Pict p)`

Showing an empty picture puts up a small gray dotted circle, so you can see that something was shown. Saving one is an error, because PNG and GIF files need at least one pixel.
