A student followed most of the recipe for a parking meter:

  1. Wrote the record: record ParkingSession(int minutes, int rate) {}
  2. Wrote the header with a placeholder, int costCents() { return 0; }, and checked that it runs.
  3. Filled in the body: return minutes * rate;
  4. Started a test, assertEquals(___, new ParkingSession(90, 300).costCents()), and got stuck: is 300 cents per minute or per hour? Is the answer 27000 or 450?

Which step did they skip that would have raised that question first?

  1. Writing example data and saying what it means in English
  2. Writing the method header
    They did write a header, in step 2.
  3. Using a placeholder so the program runs
    They did, in step 2, and it ran.
  4. Writing a helper method
    A helper would not tell them what rate means.
