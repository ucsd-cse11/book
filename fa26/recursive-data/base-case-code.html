Course prerequisites can be written with just one record:
record Course(String name, Course[] prereqs) {}
Course cse11 = new Course("CSE 11", new Course[] {});
Course cse12 = new Course("CSE 12", new Course[] { cse11 });
There is no separate record for the base case. What plays the part of the base case here?
  1. A Course whose prereqs array is empty, like cse11
    cse11 doesn’t hold any other Course, because its array is empty. A chain of prerequisites stops at a course like that.
  2. A Course with something in its prereqs array, like cse12
    cse12 holds cse11 in its array, so it refers back to Course. That makes it a recursive case.
  3. The name field, because it is a String
    String doesn’t refer back to Course, but it isn’t a Course either. The base case has to be a value of the type itself.
  4. Nothing. Without a base record, no Course can ever be built
    We built cse11 without needing a Course first, so the data does have a place to stop.
