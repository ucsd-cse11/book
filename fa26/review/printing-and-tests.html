Printing, Returning, and Tests

What does running this file print?

record Time(int hour, int minute) {
  int toMinutes() {
    return hour * 60 + minute;
  }
  void report() {
    System.out.println(hour + ":" + minute);
  }
}
void main() {
  Time t = new Time(13, 5);
  t.toMinutes();
  t.report();
}
  1. 13:5
  2. 785
13:5
    t.toMinutes() returns 785 to main, and main does nothing with it. Only System.out.println prints.
  3. 785
    toMinutes returns its answer without printing it. The one println that runs is in report.
  4. Nothing
    report is void, so it returns nothing, but its println still runs when main calls it.

Time has this method:

int minutesBetween(Time other) {
  return Math.abs(toMinutes() - other.toMinutes());
}

Which of these tests pass? Select all that do.

  1. assertEquals(90, new Time(9, 0).minutesBetween(new Time(10, 30)));
    630 - 540 is 90.
  2. assertEquals(30, new Time(8, 45).minutesBetween(new Time(8, 15)));
    Math.abs makes the order of the two times not matter.
  3. assertEquals(1, new Time(23, 59).minutesBetween(new Time(0, 0)));
    The method subtracts minutes since midnight, 1439 - 0. It doesn’t know that 23:59 and 0:00 are a minute apart across midnight.
  4. assertEquals(new Time(9, 0), new Time(9, 0));
    assertEquals uses equals, and a record’s equals compares the fields.
  5. assertEquals(new Time(1, 30), new Time(0, 90));
    Both are 90 minutes after midnight, but the fields differ: 1 and 30 against 0 and 90.
