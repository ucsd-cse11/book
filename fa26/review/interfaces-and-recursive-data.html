Interfaces and Recursive Data

record ImageData(String keywords, String fileType, int width, int height) {}

interface ImageQuery {
  boolean matches(ImageData img);
}
record HasExtension(String ext) implements ImageQuery {
  public boolean matches(ImageData img) {
    return img.fileType().equals(this.ext);
  }
}
record LargerThan(int minWidth, int minHeight) implements ImageQuery {
  public boolean matches(ImageData img) {
    return img.width() >= this.minWidth && img.height() >= this.minHeight;
  }
}
record And(ImageQuery left, ImageQuery right) implements ImageQuery {
  public boolean matches(ImageData img) {
    return this.left.matches(img) && this.right.matches(img);
  }
}
record Or(ImageQuery left, ImageQuery right) implements ImageQuery {
  public boolean matches(ImageData img) {
    return this.left.matches(img) || this.right.matches(img);
  }
}
record Not(ImageQuery query) implements ImageQuery {
  public boolean matches(ImageData img) {
    return !this.query.matches(img);
  }
}
Which of these lines compile? Select all that do.
  1. ImageQuery q = new HasExtension("png");
    HasExtension implements ImageQuery, so it can be stored under that type.
  2. HasExtension h = new Not(new HasExtension("png"));
    A Not is an ImageQuery, but it is not a HasExtension.
  3. ImageQuery both = new And(new LargerThan(600, 400), new Not(new HasExtension("gif")));
    Both fields of And are ImageQuerys, and LargerThan and Not each implement it.
  4. ImageQuery any = new ImageQuery();
    An interface has no constructor. Only the records that implement it can be built.
  5. ImageQuery either = new Or("png", "jpg");
    Or’s fields are ImageQuerys, and a String isn’t one.
