You ask an AI assistant for a Menu method that “returns the cheapest price on the menu,” and it writes this:

int cheapest() {
  int best = pricesCents[0];
  for(int p: pricesCents) {
    if(p < best) { best = p; }
  }
  return best;
}

The code assumes something about a Menu that the request never said. What?

  1. The menu has at least one price
    pricesCents[0] stops with an ArrayIndexOutOfBoundsException on an empty array. The request didn’t say what the cheapest price of an empty menu is, and this code chose “crash.”
  2. The prices are in order from lowest to highest
    The loop compares every price with best, so the lowest one is found wherever it sits.
  3. No two prices are the same
    With a tie, p < best is false for the second copy, and best already holds the right price.
  4. Every price is more than 0
    p < best works the same for any ints, negative ones included.
