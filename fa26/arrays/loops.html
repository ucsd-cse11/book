Prof: Indeed. We just saw two things at once:
  • Assignment – the definition of closest starts as the first value in the array, and then changes when we use closest = p
  • A for loop – the syntax for(Point p: points) { /* loop body */ }. It runs the loop body once for each element of points, and each time it runs, the next element is stored in p.
These two things tend to go together in programming: many loops that we want to write only work with assignment.
And one other bit of jargon – a mathy name for a best-so-far loop that returns the element that is the “smallest” in some way is argmin, which you might see in other contexts. Here that “something” is the distance to a target.

record Pizza(double inches, int costCents) {
  double area() {
    double radius = inches / 2;
    return radius * radius * Math.PI;
  }
  boolean betterDeal(Pizza other) {
    return costCents / area() < other.costCents / other.area();
  }
}
