Here is usernames with one line left out. With the same cse11 as above, what does the book show for names?

String[] usernames() {
  String[] result = new String[students.length];
  int index = 0;
  for(Student s: students) {
    result[index] = s.username;
  }
  return result;
}
  1. names = [ghopper, null, null]
  2. names = [alovelace, null, null]
    Every run of the body writes to result[0], so each username replaces the one before it. The last one stays.
  3. names = [alovelace, aturing, ghopper]
    Without index += 1, index is 0 every time, so the body only ever changes result[0].
  4. It doesn’t compile
    Nothing is wrong with the program’s types, so it compiles. It just doesn’t do what the method promises.
