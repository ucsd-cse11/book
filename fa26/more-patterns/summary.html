A Post has a replies list and a replyTo field, as in this chapter. Which method never finishes when it is called on a post that has a reply?
  1. int count() {
  int total = 1;
  if (this.replyTo != null) { total += this.replyTo.count(); }
  for (Post r : this.replies) { total += r.count(); }
  return total;
}
    The reply’s replyTo is the post that called it, so the two keep calling each other.
  2. int count() {
  int total = 1;
  for (Post r : this.replies) { total += r.count(); }
  return total;
}
    This only goes down through replies. It stops at posts with no replies.
  3. int count() {
  if (this.replyTo == null) { return 1; }
  return 1 + this.replyTo.count();
}
    This only goes up through replyTo. It stops at the post whose replyTo is null.
