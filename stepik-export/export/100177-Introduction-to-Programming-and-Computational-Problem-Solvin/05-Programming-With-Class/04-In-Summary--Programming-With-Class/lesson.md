# In Summary — Programming, With Class


---

<!-- step 2331713 | type: text -->

<p>In this section, we learned several new things:</p>

<ul>
	<li>
	<p>We refined what goes in a <strong>class definition</strong> – it can also contain a <strong>constructor</strong>, which lets us set the fields differently for different instances.</p>
	</li>
	<li>
	<p>We saw that a <strong>field</strong> doesn’t necessarily need to come with a value; rather than always having the same value, it can instead be provided with a value when using <code>new</code>.</p>
	</li>
	<li>
	<p>We introduced the <code>new</code> keyword, which allows us to create instances of a class with specified values for the different fields.</p>
	</li>
	<li>
	<p>We distinguished between <strong>objects</strong> and <strong>references</strong>, both in the printed output we get when running programs and in a new picture-based representation of values.</p>
	</li>
	<li>
	<p>The special name <code>this</code> can be used in a method as a reference to the object that was to the left of the dot when the method was called.</p>
	</li>
</ul>
