# In Summary — Programming, Methodically


---

<!-- step 2399416 | type: text -->

<p>In this section, we introduced some important concepts:</p>

<ul>
	<li>
	<p>We learned that we can use <strong>methods</strong> to repeat calculations for different values, which drastically reduces the amount of code that we need to write.</p>
	</li>
	<li>
	<p>We found out that every method definition contains the same basic structure called a <strong>method header</strong>, which describes the behavior of the method in question.</p>
	</li>
	<li>
	<p>We followed the <strong>design recipe</strong> step by step to create a method that will give us the solution to a problem statement.</p>
	</li>
	<li>
	<p>We discovered that methods have their own set of unique errors to watch out for, some of which occur when the various parts of a method do not match up with one another.</p>
	</li>
</ul>
