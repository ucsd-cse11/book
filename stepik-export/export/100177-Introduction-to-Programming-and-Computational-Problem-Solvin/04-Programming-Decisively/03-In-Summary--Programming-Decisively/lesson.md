# In Summary — Programming, Decisively


---

<!-- step 2327576 | type: text -->

<p>We introduced several new ideas in this section:</p>

<ul>
	<li>
	<p><strong>The <code>boolean</code> type</strong>: there are two <code>boolean</code> values, <code>true</code> and <code>false</code>, that are useful for representing computations that ask yes/no questions.</p>
	</li>
	<li>
	<p><strong>Comparison Operators</strong>: <code>&lt;</code>, <code>&gt;</code>, <code>==</code>, <code>&lt;=</code>, and <code>&gt;=</code> are all operators that take two numbers and return <code>true</code> or <code>false</code> depending on if the relationship holds.</p>
	</li>
	<li>
	<p><strong><code>if</code> statements</strong>: Comprised of <strong>conditions</strong> and <strong>branches</strong>, <code>if</code> statements use <code>boolean</code> values to select which of several expressions to evaluate.</p>
	</li>
	<li>
	<p><strong>Boolean Operators</strong>: <code>&amp;&amp;</code> and <code>||</code> (pronounced “and”, “or”) combine <code>boolean</code> values according to specific rules. These let us express conditions that combine several different answers.</p>
	</li>
</ul>
