# In Summary — Arrays and main


---

<!-- step 2354437 | type: text -->

<p>In this module, we learned that:</p>

<ul>
	<li>
	<p>We can represent a <strong>collection</strong> of data using an <strong>Array</strong>. An array can contain multiple values, and its contents are stored in memory.</p>
	</li>
	<li>
	<p>A <strong><code>static</code></strong> method is not called on an instance of the class that it's in. Rather, it is called by <code>&lt;Class name&gt;.methodName()</code></p>
	</li>
	<li>
	<p>A program that has a <strong><code>main()</code></strong> method can be run using <code>javac</code> and <code>java</code>, and the program will start running at the beginning of the <code>main()</code> method.</p>
	</li>
	<li>
	<p>A return type of <strong><code>void</code></strong> in Java indicates that the method does not return any value.</p>
	</li>
	<li>
	<p>Including the line <code>System.out.println(&lt;some value&gt;);</code> in our program allows us to print some output to the terminal.</p>
	</li>
</ul>
