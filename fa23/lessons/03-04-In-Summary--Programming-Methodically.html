3.4 — In Summary — Programming, Methodically

1

In this section, we introduced some important concepts:

  • We learned that we can use methods to repeat calculations for different values, which drastically reduces the amount of code that we need to write.

  • We found out that every method definition contains the same basic structure called a method header, which describes the behavior of the method in question.

  • We followed the design recipe step by step to create a method that will give us the solution to a problem statement.

  • We discovered that methods have their own set of unique errors to watch out for, some of which occur when the various parts of a method do not match up with one another.
