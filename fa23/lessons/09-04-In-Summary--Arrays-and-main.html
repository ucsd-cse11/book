9.4 — In Summary — Arrays and main

1

In this module, we learned that:

  • We can represent a collection of data using an Array. An array can contain multiple values, and its contents are stored in memory.

  • A static method is not called on an instance of the class that it's in. Rather, it is called by <Class name>.methodName()

  • A program that has a main() method can be run using javac and java, and the program will start running at the beginning of the main() method.

  • A return type of void in Java indicates that the method does not return any value.

  • Including the line System.out.println(<some value>); in our program allows us to print some output to the terminal.
