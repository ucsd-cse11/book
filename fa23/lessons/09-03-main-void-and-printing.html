Now, we are going to learn how to write stand-alone programs that do not depend on the tester library. The key method that enables us to write such stand-alone Java programs is the main() method.

It turns out the ./run command was doing a lot of work for us to display output. We will need to use other tools to get meaningful results from our program when we use java, javac, and a main() method.



First, an observation. The place where the main method says void is the position for its return type. A return type of void indicates that the method doesn't return a value. The fact that main() has a void return type helps us understand that the method itself isn't going to return a value that gets printed out for us; we'll need to find a way to do that in Java ourselves.

Short answer
Now, let's figure out how we can get our program to produce some sort of output when we run it.



We can insert a line of code that outputs, or "prints", some value to the terminal. A print statement in Java looks like this:



System.out.println();



Inside the parentheses, we can put some value that we want to output, and that value will be printed in the output of the program.

Summary



    
	
  • We can run standalone programs, without using the tester library, by writing a main() method.
    • 
	
  • The program starts running at the beginning of the main() method.
    • 
	
  • In our terminal, we can run a program that has a main() method by running 2 commands: first javac <name of file> and then java <name of class>
    • 
	
  • The method header for the main method must be public static void main(String[] args). The only part that can change is the name args.
    • 
	
  • A method that has a return type of void does not return any value.
    • 
	
  • A program, when run without any errors, will have no output in the terminal unless we include print statements.
