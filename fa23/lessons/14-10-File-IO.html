14.10 — File IO

123456

Being able to write to and read from a file is a very important skill. The ability to save information or get data more than what you can simple put in args when running a program is incredibly useful.

We will take a good look at the following code.

import java.nio.file.*;
import java.io.IOException;

class FileExample {
    public static void main(String[] args) throws IOException {
        String contents = Files.readString(Paths.get("quotes.txt"));
        System.out.println(contents);

        String[] words = contents.split(" ");
        for (String word: words) {
            System.out.println(word);
        }
    }
}

 First note that we have

import java.nio.file.*;

 which is necessary as it is what provides our file methods like Files.readString and Paths.get so we can handle files. If we do not import this we will get the following error when attempting to compile the rest of the code.

 It knows neither the static Files or Paths class so it cannot compile.

The next important line we have is

        String contents = Files.readString(Paths.get("quotes.txt"));

which has 2 important function calls to functions we did not ourselves write so to javadocs we go.

First up is readString:

static String readString​(Path path)

Reads all content from a file into a string, decoding from bytes to characters using the UTF-8 charset.

 We see that it takes a path, and how do we get this? We have another method to help us:

static Path get(String first, String... more)

Converts a path string, or a sequence of strings that when joined form a path string, to a Path.

Now that we have gotten our Path object and called readString with it as the parameter, we have the string from the file! (stored in "contents").

and it has done exactly that. It reads the whole file, not stopping until End Of File (EOF) is reached. Then to print each word out on it's own line in the output we split on each space character and print.

One of the most important features of a programming language is support for file manipulation, i.e., reading from and writing to files. Java provides extensive support for a wide range of file operations through streams. We use the word “stream” here to describe the flow of data either from a file to a Java program (reading) or vice versa (writing).

There are many different ways to work with streams in Java. We will not include all of them here. Our very simple code snippet below shows how we can read all lines in a text file and print them out to the terminal using the Scanner class:

File file = new File("input.txt");

Scanner sc = new Scanner(file);

while (sc.hasNextLine()) {
    String line = sc.nextLine();
    System.out.println(line);
}

To begin with, we create a File object for the file that we want to read: input.txt. Note that this is not the same as creating the file on our hard drive: The file already exists, and we are just creating a Java object associated with it.

Next, we create a Scanner object, and give it the file object we created earlier. This file object will serve as our input stream from which the scanner will get its data.

Finally, in a while loop, we use the hasNextLine method to see if there are more lines in the file left to be read, if so, we read the line by calling the nextLine method on the scanner object, and print it out using System.out.println.

As we mentioned above, this is only a very simple example of file operations in Java. There are many other classes that can be used other than the Scanner class, which you are welcome to explore after you become more familiar with the Java language.
