4.3 — In Summary — Programming, Decisively

1

We introduced several new ideas in this section:

  • The boolean type: there are two boolean values, true and false, that are useful for representing computations that ask yes/no questions.

  • Comparison Operators: <, >, ==, <=, and >= are all operators that take two numbers and return true or false depending on if the relationship holds.

  • if statements: Comprised of conditions and branches, if statements use boolean values to select which of several expressions to evaluate.

  • Boolean Operators: && and || (pronounced “and”, “or”) combine boolean values according to specific rules. These let us express conditions that combine several different answers.
