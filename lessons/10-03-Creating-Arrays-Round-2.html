Matching

We saw how we can create arrays with array initializers. This is a somewhat limited approach, since it can only create arrays with a size that’s known when we write the program. It’s useful to be able to create arrays whose sizes are determined by the program itself. This works differently than using initializers.

It's useful to have a method that takes two numbers and produces an array of numbers from the first up to the second. We could use this to create a numbered list, for example. This is different than the methods we’ve written so far, because it doesn’t take a reference to an array as input. Instead, it produces one as output. Let’s think about the header first:

/*
  @param start The number to start from
  @param end The number to end before
  @return a reference to a new array containing integers from start (inclusive)
  to end (exclusive)
*/
int[] range(int start, int end) {}

This warrants a few examples:

boolean testRange(Tester t) {
  int[] check1 = {0, 1, 2};
  t.checkExpect(this.range(0, 3), check1);
 
  int[] check2 = {};
  t.checkExpect(this.range(0, 0), check2);
 
  int[] check3 = {5};
  t.checkexpect(this.range(5, 6), check3);
 
  int[] check4 = {5, 6, 7, 8};
  t.checkexpect(this.range(5, 9), check4);
}

The size of the array we want to create will be different depending on the argument values. We need two new Java features to write this method body because we don't know of any array initializer that will create a different array depending on the arguments. That is, how can we fill in the ??? below with an array that always has the right size based on start and end?

int[] range(int start, int end) {
  int[] result = ???

Here’s the first of the new features we need: we can create an array of a specified size with the following syntax:

new Type[size]

where size is some expression that calculates an int. For example, before going back to the range() method, we can think about this as an example:

class ExamplesArrays {
  int[] nums = new int[3];
}

Note that the values of all the elements of the newly created array are 0! When we create an array using the new operator, all the elements get a specific default value. For int and double arrays, that value is 0. There are 3 elements in this array because we specified the size 3 in new int[3].

This leaves us with a question. If the arrays get created full of default values, how can we create an array that contains the values we want? The answer is the second new feature we need, which is array assignment. This assigns values into the indices in an array, and the syntax is:

someArray[index] = newVal;

We can see this in action with a simple method that creates a fixed-size array and sets its contents:

int[] simpleArrayCreator() {
  int[] nums = new int[3];
  nums[0] = 88;
  nums[1] = 95;
  nums[2] = 1000;
  return nums;
}

Fill in the blanks

We can apply these two new features to fill in the body of range():

int[] range(int start, int end) {
  int[] result = new int[end - start];  // creates a new array of int of size (end - start)
  for(int i = start; i < end; i += 1) {
    result[i - start] = i;              // assigns into the appropriate start field
  }
  return result;
}

There are a few interesting things going on here.

  • First, we create an array of the correct size right at the beginning of the method. This is a common pattern in array-processing methods, which is to compute the correct size and create the resulting array first.
  • Next, we loop the index i from start to end, so i will take on the values 5, 6, 7, and 8 on the different iterations of the loop. When we perform the array assignment, we are careful to use i - start to make sure that we don’t use indices that are too large for the array and will always start at index 0.

The tabular description helps us see the values within the array at each step and how they are incrementally filled in – in each step, we can see that the index of i - start is filled in in the rightmost column.
